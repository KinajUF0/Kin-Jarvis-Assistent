Ассистент реагирует **ТОЛЬКО** на эти имена:

| Имя | Язык |
|-----|------|
| **Джарвис** | 🇷🇺 |
| **Jarvis** | 🇬🇧 |
| **Кин** | 🇷🇺 |
| **Kin** | 🇬🇧 |
| **Астра** | 🇷🇺 |
| **Astra** | 🇬🇧 |

> ⚠️ На «Алиса», «Siri», «Google» и другие имена ассистент **не реагирует**.

## 💬 Разговор

| Команда | Действие |
|---------|----------|
| `Кин, как дела?` | Обычный разговор |
| `Джарvis, расскажи анекдот` | AI-ответ через Gemini |
| `Астра, что такое Python?` | Объяснение / ответ на вопрос |
| `Jarvis, what's the weather?` | Ответ на английском |

## 🎤 Голосовое управление

1. Нажмите **«АКТИВИРОВАТЬ»** — непрерывное прослушивание
2. Или нажмите **🎤** — одноразовая запись
3. Или **введите текст** в поле ввода

---

## Добавление своих программ

Отредактируйте `config/apps.json`:

```json
"myapp": {
  "display_name": "Моя программа",
  "process_names": ["myapp"],
  "paths": ["C:\\Path\\To\\myapp.exe"]
}
```

Затем: `Кин, открой myapp`
