# Ollama — локальный AI для Kin Jarvis

## Быстрая установка (Windows)

```bat
scripts\install_ollama.bat
```

Скрипт:
1. Установит Ollama (через winget или откроет сайт)
2. Скачает модель `llama3.2` (~2 GB)

## Вручную

1. Скачай: [ollama.com/download](https://ollama.com/download/windows)
2. Установи и запусти (иконка в трее)
3. В терминале:
   ```bat
   ollama pull llama3.2
   ```

## Модели для русского языка

| Модель | Размер | Для чего |
|--------|--------|----------|
| `llama3.2` | ~2 GB | По умолчанию, хороший баланс |
| `qwen2.5:3b` | ~2 GB | Лучше понимает русский |
| `gemma2:2b` | ~1.5 GB | Быстрая, слабый ПК |

Сменить модель в `.env`:
```
OLLAMA_MODEL=qwen2.5:3b
```

## Как Kin использует Ollama

1. **Команды** (Discord, окна, браузер) — **локально**, Ollama не нужен
2. **Разговор и вопросы** — через Ollama
3. **Не понял команду** — Ollama пробует разобрать

## Проверка

```bat
ollama list
curl http://127.0.0.1:11434/api/tags
```

В Kin Jarvis: sidebar покажет **Ollama OK** или подсказку что не так.

## Работает в России

Ollama работает **полностью локально** — без VPN, без лимитов Google.
